Guidelines

Setup Phase: Move the cubes and agent to reuired position

Click on "Setup" to edit the layout and generate NavMesh again.

Generate NavMesh Phase: This created NavMesh for the grid.
Click on "Generate Nav Mesh" button. (This will enable "Find Path" and "Show/Hide Debug Overlay" buttons)
This will give us a NavMesh which has Rectangle Portals. It can be visualized using Debug view.

Find Path Phase:
Click on the ground to select 'target position' for agent. (It will be marked by yellow point.)
Click and drag agent in the scene to move it around. (It will me blue color cylinder.)

Click on "Find Path" button to find out the shortest path using A* algorithm.
Note: It will not generate path if final destination is on forbidden region.

Camera Controls:
Hold 'alt' key to move the camera.

Legend

Blue -> NavMesh agent
Grey -> Cubes
Brown -> Ground
Yellow -> Agent Target Position
